# DevUniverse

DevUniverse is a software engineering project that simulates a real tech company, where developers work on projects, manage tasks, write code, test features, and follow professional development workflows.

The project is built to develop practical software engineering skills through hands-on development.

## Tech Stack

- **Backend:** C# / ASP.NET Core
- **Frontend:** React / Next.js / TypeScript
- **Database:** PostgreSQL
- **AI Integration:** To be determined
- **Cloud:** Microsoft Azure (planned)

## Current Development

Building the backend foundation, starting with the Developer Profile API using controllers, services, models, DTOs, and CRUD operations.

## Project Status

🚧 Under active development — features are being built and improved incrementally.
